# АРХИТЕКТУРА PRODAVAN OS: Проектирование долгосрочной системы знаний

## 1. Концепция: Знания как Операционная Система (OS)

PRODAVAN OS строится не как статичная книга или разовый обучающий курс. Это децентрализованная, версионируемая система знаний, спроектированная по канонам разработки масштабируемых open-source систем (аналогично Linux Kernel).

---

## 2. Ключевые компоненты инфраструктуры

### 2.1. Git как фундамент версионирования
- **Ветки:**
  - `main` — стабильное каноническое ядро метода (проверенное десятками компаний).
  - `candidate` — гипотезы и регламенты, проходящие 90-дневную обкатку в текущих потоках Лаборатории.
  - `experiment/*` — отраслевые адаптации (B2B сложные сделки, EdTech, опт, онлайн-услуги).
- **Семантическое версионирование (SemVer для менеджмента):**
  - `vMAJOR.MINOR.PATCH`
  - `MAJOR` (v1.0, v2.0): Смена ключевой парадигмы, выход полной книги/стандарта.
  - `MINOR` (v0.2, v0.3): Добавление нового принципа, матрицы процессов или когортного формата.
  - `PATCH` (v0.1.1): Уточнение формулировок вопросов анкеты, исправление формул.

### 2.2. Obsidian-совместимость (Второй мозг и Граф Знаний)
Все документы внутри репозитория связаны двусторонними вики-ссылками формата `[[...]]`.
Каждый файл содержит YAML-frontmatter:
```yaml
---
id: PR-01
title: Рабочая забота
type: principle
status: stable
tags: [management, care, culture]
aliases: [Рабочая забота, Work Care]
related: ["[[01_Philosophy/01_Человекоцентричность]]", "[[04_Research/01_Научный_базис]]"]
---
```
Это позволяет открыть репозиторий в **Obsidian** и получить интерактивный живой граф взаимосвязей: от философии к принципу, от принципа к кейсу Дины, от кейса к правилу для ИИ-РОПа.

### 2.3. RAG-совместимость (Vector DB для ИИ-РОПа)
Папка `06_AI_ROP` структурирована так, чтобы любой LLM-пайплайн мог напрямую использовать документы репозитория как базу знаний (Knowledge Base):
- Атомарные чанки (1 мысль = 1 карточка).
- Жесткие деревья решений (Decision Trees) в формате Markdown.
- Четкие триггеры и антипаттерны («Если собственник требует X, проверь Y»).
